# 02. 动态数组

动态数组是 `std::vector` 背后的核心思想：用一段连续内存保存元素，容量不够时申请更大的内存，把旧元素搬过去。

## 核心性质

- 按下标访问：`O(1)`。
- 尾部插入：均摊 `O(1)`。
- 中间插入或删除：`O(n)`，因为需要移动元素。
- 内存连续：缓存友好，遍历通常很快。

## 为什么尾部插入是均摊 O(1)

当容量够时，`push_back` 只写入一个位置，是 `O(1)`。

当容量不够时，需要：

1. 申请更大的数组。
2. 把旧元素搬过去。
3. 释放旧数组。

这一次很贵，但扩容不是每次发生。如果每次容量翻倍，很多次 `push_back` 平摊下来仍然是均摊 `O(1)`。

## 代码观察点

看 [include/ds/dynamic_array.hpp](../include/ds/dynamic_array.hpp)：

- `ensure_capacity_for_one_more`：决定何时扩容。
- `reserve`：真正申请新空间并移动旧元素。
- `insert`：从后往前移动元素，给新值腾位置。
- `erase`：从前往后覆盖元素，填上空洞。
